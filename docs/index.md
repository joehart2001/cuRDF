# cuRDF

GPU-accelerated radial distribution functions using NVIDIA ALCHEMI Toolkit-Ops
and PyTorch, with ASE and MDAnalysis adapters for structures and trajectories.

The published documentation is at <https://joehart2001.github.io/cuRDF/>.

- [Quickstart](quickstart.md): installation, a first RDF, trajectories, and saving results.
- [Methods](methods.md): radial bins, normalization, trajectory averaging, and periodic boundaries.
- [API](api.md): functions, parameter defaults, and output formats.
- [Troubleshooting](troubleshooting.md): CUDA setup, species labels, cells, and neighbour capacity.
